# History Sourced — Style DNA

Concept: **"the evidence table."** The channel name promises sources, so the visuals show them. Dark ink-blue map table, parchment cards, an oxblood ink line tracing what happened. Not sepia-filter, not generic "epic" trailer style.

Use for every History Sourced long video (incl. "History Sourced: Unsolved"), Short and thumbnail. Content in English; talk to the user in Turkish.

## Fonts (free, OFL)
From `https://raw.githubusercontent.com/google/fonts/main/`:
- `ofl/imfellenglish/IMFeENrm28P.ttf` — titles, place names (period-printed feel)
- `ofl/imfellenglish/IMFeENit28P.ttf` — quotes from primary sources
- `ofl/archivonarrow/ArchivoNarrow[wght].ttf` (URL-encode brackets as %5B %5D) — dates, labels, source cards, captions; weights 500–700

Never use Cinzel, Trajan, Cormorant, Bebas, Montserrat — the default "history channel" fonts.

## Layout (1920×1080)
- Faint lat/long grid every 120px across the whole frame.
- Top-left: date + place in Archivo Narrow 700, brass, all caps ("AUGUST 1914 · EAST PRUSSIA").
- Title in IM Fell 110–130px, parchment, max 2 lines.
- Primary-source quote in IM Fell Italic, pale, in real curly quotes.
- Right half: the map / scene / document image.

## Signature moves
1. **Source card (mandatory)** — whenever a key claim is stated, a parchment card with an oxblood "SRC" tab slides in at −2° rotation: `PRIMARY SOURCE · No. N` + the real document name and date. Only real sources from the research; never invent one. This is the channel's fingerprint.
2. **Ink route** — movements drawn as an oxblood line that draws itself (path revealed over 1–2 s), circle markers at start/end, arrowhead at the end.
3. **Evidence pin** — images enter as "pinned" prints: slight rotation (−3° to 3°), soft shadow, settle with a tiny overshoot.
4. **Date stamp** — brass date ticks like a counter when the story jumps in time.
5. **Unsolved mode** — for the Unsolved series, an oxblood "UNRESOLVED" label and a question-mark card list competing theories, each with its own source card.

## Motion & editing
- Narrative rhythm: context (slow, map-wide) → event (faster cuts, routes drawing) → consequence (slow, single quote on screen with silence).
- Leave 1–2 s of near-silence after the most important quote; it lands harder than music.
- Grain 0.06–0.08; slight vignette. No lens flares, no fake fire/smoke overlays.
- Captions: Archivo Narrow 600, parchment text on #141B26 at 85% opacity, 3–5 words, key name or number in brass.

## Thumbnails
Dark map table, one strong image (portrait, artifact or map detail), 2–4 words in IM Fell parchment, and a small source card or "UNSOLVED" tag in the corner. Same layout family every time, different image and accent placement.

## Anti-template rule
Vary the opening per video (cold open on a quote / on a map / on the aftermath), vary which signature move leads, and keep each script a real story arc with checked sources. Log episode → hook type → lead move in the project and check it before each production. This keeps the channel distinct and clear of YouTube's repetitive-content demonetization.

## Before delivering
Render sample frames and look at them: fonts loaded, every on-screen source card matches a real source in the research notes, routes geographically correct, text inside safe margins.
